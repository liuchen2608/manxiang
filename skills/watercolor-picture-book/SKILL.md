# 水彩绘本

## 内容与视觉依据

角色参考图读取当前角色卡；单格漫画同时读取当前分镜的标题、镜头、场景动作及角色参考图。角色年龄、体型、服装、事件和情绪保持作者设定，绘本画风不意味着将所有角色儿童化或将所有场景改为温馨氛围。

用透明色层、纸张纹理和软硬边缘表现水彩媒介。五官、手势、服装图案及关键物件保持清晰；背景晕染服务空间层次。标志性配色保持一致，其他媒介的参考图转译为水彩笔触。

## 模板与执行

读取 [templates.json](templates.json)，作为视觉描述、正向和反向提示词的唯一来源。

1. 将当前角色的姓名、身份、外貌服装及性格填入 characters。
2. 角色参考图使用 reference 模板；单格漫画使用 panel，填入当前标题、镜头和场景。
3. 合并 style 与模式模板，将 negative 放入“避免出现”段落。图片接口使用合并后的 prompt，不发送独立 negative_prompt 参数。
4. 将提示词交给已配置的图片接口；单格编辑请求附带角色参考图。对白、旁白与标题由应用排版。

应用执行器为 `lib/watercolor-picture-book.ts`，输出 skill、version、mode、positive_prompt、negative_prompt、aspect_ratio、size 和 prompt。变量仅替换一次，用户内容中的模板符号按原文保留。当前使用横向 3:2、1536×1024。

“水彩绘本”选项绑定此技能；点击生成角色参考图、绘制漫画或单格重绘时执行。选择画风本身不发送请求。切换画风标记已有参考图与分镜为待更新，保留原图直到生成成功。

## 完成检查

实际请求包含水彩视觉约束和当前角色、当前分镜，单格请求附带角色参考图。输出应兼具自然水彩质感与清晰主体，保持角色辨识度及剧情情绪，不混入其他画风模板或固定示例故事。
