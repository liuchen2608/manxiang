# 日系彩漫提示词模板

## 输入与内容依据

- character_reference：读取当前角色的身份、外貌、服装、配饰和体型。
- comic_panel：同时读取当前分镜的标题、镜头、场景与动作，并使用角色参考图。
- 时间、天气、情绪、主体位置及必须保留的细节以角色卡和分镜描述为准。
- 默认方形构图。当前应用适配为 1024×1024。

角色与剧情保持作者设定；画风只改变视觉表达。雨夜、黄雨衣女孩、白猫、邮局是来源示例，不作为其他故事的默认元素。

## 模板与执行

读取同目录的 [templates.json](templates.json)，作为正向、反向提示词的唯一模板来源。

1. 将各角色展开为姓名、身份、外貌和性格描述。
2. 角色设定图填充 reference 模板；单格漫画填充 panel 模板。
3. 叠加 style 描述，并将 negative 合并到“避免出现”段落。
4. 填充模板后直接交给已配置的图片接口；不需要额外的语言模型调用。
5. 图片编辑模式附带角色参考图，维持人物外观与服装一致。

应用执行器位于 `lib/japanese-color-comic.ts`。替换变量仅执行一遍，角色或分镜文本中的模板样式字符仍视为用户内容。

## 条件视觉增强

仅在当前分镜已经明确这些条件时增强对应细节：

- 雨夜：细雨、伞面水珠、湿润地面、积水倒影和涟漪。
- 夜间暖灯：冷色环境与暖色局部灯光对比。
- 晴天：自然日光、通透色彩和柔和投影。
- 室内：依照窗光、灯光或烛光组织明暗。

没有明确的天气或照明条件时，按当前场景自然表现，不套用雨夜示例。

## 输出与调用约定

执行器输出 skill、version、mode、positive_prompt、negative_prompt、aspect_ratio、size 和合并后的 prompt。

选择“日系彩漫”即绑定此技能；点击生成角色参考图、绘制漫画或单格重绘时执行。选择画风本身不发送生成请求。切换画风后已有参考图与分格标记为待更新，保留原图直到生成成功。

当前图片接口通过统一 prompt 接收反向约束，不发送独立 negative_prompt 参数。技能不保存密钥、不切换用户选定的接口。

## 完成检查

- 模板字段来自当前角色与当前分镜。
- 场景模式只绘制一个瞬间；设定图模式展示完整角色。
- 单格图片请求实际附带角色参考图。
- 对白由界面排版，不作为图片内文字生成。
- 默认比例与实际图片请求均为 1:1。
- 未将来源示例人物、地点和天气添加到无关故事。
