# 美式漫画

## 内容与视觉依据

角色参考图读取当前角色卡；单格漫画同时读取当前分镜的标题、镜头、场景动作及角色参考图。美式画风改变墨线、光影与上色方式，角色年龄、体型、服装、时代和事件保持作者设定，不默认套用超级英雄制服或夸张肌肉。

使用清晰轮廓、黑色阴影块面和印刷色彩组织画面，半色调与排线服务体积。按指定镜头构图；只有动作场景才增强运动线和透视缩短，静态场景保持原有情绪与节奏。

## 模板与执行

读取 [templates.json](templates.json)，作为视觉描述、正向和反向提示词的唯一来源。

1. 将当前角色姓名、身份、外貌服装和性格填入 characters。
2. 参考图使用 reference；单格漫画使用 panel，填入当前标题、镜头和场景。
3. 合并 style 与模式模板，将 negative 放入“避免出现”段落。图片接口使用合并后的 prompt，不发送独立 negative_prompt 参数。
4. 通过已配置的图片接口生成，单格编辑请求附带角色参考图。对白、旁白、拟声词和标题由应用排版，不要求绘图模型生成文字。

应用执行器为 `lib/american-comic.ts`，输出 skill、version、mode、positive_prompt、negative_prompt、aspect_ratio、size 和 prompt。变量仅替换一次，用户内容中的模板符号按原文保留。当前使用横向 3:2、1536×1024。

“美式漫画”选项绑定此技能；点击生成角色参考图、绘制漫画或单格重绘时执行。选择本身不发送请求。切换画风标记已有参考图与分镜为待更新，保留原图直到生成成功。

## 完成检查

实际请求应包含当前角色、当前分镜与美式视觉约束，单格请求附带角色参考图。输出保持人物辨识度、指定镜头和当前事件；不会因为选择画风而额外引入战斗、英雄身份或其他模板的视觉规则。
